2人シーンは人数範囲に2人が含まれると100点、それ以外は0点。Pythonの安定ソートで同点をカタログ順に維持し、先頭12本を掲載していた。人気・販売・レビュー・実プレイの順位ではない。難易度等の5段階値は編集評価であり公式評価ではない。診断は人数・時間・協力モードを必須条件として別の編集加点を行う。

選択肢A（掲載順を保持し説明を正確にする）を採用。B（時間等で並べ替える）は短いほど全員に適する根拠がなく不採用。C（専用・初心者等の新しい分類）は全商品の確認なしには追加しない。既存の比較表と診断で人数・所要時間・年齢・協力／対戦を比較できる。2人対応は2人専用を意味せず、専用表記は追加しない。

PR #6で人数上限2を修正した後、本番APIの商品名が「コードネーム：デュエット 2025年新版 日本語版」（book:21815637）と確認できた。CGE原版2017の10歳・15–30分はこの購入先に対応しないため、追加修正で日本版公式 https://hobbyjapan.games/codename_duet/ の2025年新版に合わせ11歳以上・約15分・2人以上とする。比較表・カード・詳細に対象版を明記する。商品取得と公開境界の既存match_itemで2025・日本語版の明示を必須にし、旧版や版不明を代用しない。候補不在時は従来どおり楽天検索へ案内し架空の直接購入先を補わない。

人数上限はnullと明示的open-ended・出典を保存し、未知の上限一般を無制限扱いしない。訂正した時間と人数は診断にも反映する。新版の15分に基づき既存の短時間フィルターにも入るが、編集加点・人数/時間/協力の必須条件は変更しない。2人ページの12本と順序、title・description・H1・canonical・ItemList、楽天リンク／画像の対応は同一の公開商品スナップショットによる前後比較で検証。320/390/1440pxの実ブラウザー証拠を既存preflightのartifactへ保存する。SEO・収益への効果は未測定。
